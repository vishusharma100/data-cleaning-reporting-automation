# Data Cleaning & Reporting Automation

A portfolio-ready Python + Power BI project that cleans a synthetic sales dataset, records data-quality metrics, creates automated summaries, and exports visual reports.

## Project goals

- Detect and remove exact duplicate rows.
- Normalize inconsistent text labels and whitespace.
- Handle missing values and invalid quantities/prices/discounts with documented rules.
- Recalculate sales consistently.
- Generate cleaned data, data-quality metrics, sales summaries, charts, and an executive summary.
- Import the cleaned CSV into Power BI for an interactive dashboard.

## Tech stack

Python, Pandas, NumPy, Matplotlib, Jupyter Notebook, Power BI Desktop.

## Setup (Windows / PowerShell)

1. Install Python 3.10+ from https://www.python.org/downloads/ and tick **Add Python to PATH**.
2. Open PowerShell in the project folder.
3. Create and activate a virtual environment:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt and run `.venv\Scripts\activate.bat`, or continue with `.venv\Scripts\python.exe`.

4. Install packages:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

## Cleaning rules

| Issue | Rule |
|---|---|
| Exact duplicate rows | Drop duplicates; report count |
| Text whitespace / inconsistent casing | Strip whitespace and title-case labels |
| Invalid or unparseable dates | Parse safely; drop rows with invalid order date |
| Missing price | Fill with median unit price |
| Missing discount | Fill with 0 (no discount assumed) |
| Discount outside 0–1 | Treat as invalid and fill with 0 |
| Quantity <= 0 | Treat as invalid and drop transaction row |
| Missing region/channel/product/category | Fill with `Unknown` |
| Missing customer ID | Fill with `Unknown`, never invent identity |
| Sales amount | Recalculate as Quantity × Unit Price × (1 − Discount) |

**Important:** These are example business rules for a synthetic portfolio dataset. In a real company, confirm imputation/drop rules with the data owner before production use.

## Power BI dashboard guide

1. Run `python src/main.py` first.
2. Open Power BI Desktop.
3. Select **Get data → Text/CSV** and load `data/cleaned_sales_data.csv`.
4. In Power Query, confirm `Order_Date` is Date and numeric fields are numeric.
5. Create measures:

   ```DAX
   Total Sales = SUM(cleaned_sales_data[Sales_Amount])

   Total Orders = DISTINCTCOUNT(cleaned_sales_data[Order_ID])

   Units Sold = SUM(cleaned_sales_data[Quantity])

   Average Order Value = DIVIDE([Total Sales], [Total Orders])

   Average Discount = AVERAGE(cleaned_sales_data[Discount])
   ```

6. Recommended visuals:
   - Cards: Total Sales, Total Orders, Units Sold, Average Order Value
   - Line chart: `Order_Date` by month vs Total Sales
   - Bar chart: Product vs Total Sales
   - Bar/column chart: Region vs Total Sales
   - Donut chart: Sales_Channel by Total Sales
   - Slicers: Order_Date, Region, Product, Sales_Channel
7. Save the file as `dashboard/sales_reporting_dashboard.pbix`.

The `.pbix` file is created and saved from Power BI Desktop on your computer; it is not generated by the Python pipeline.

## Data dictionary

| Column | Description |
|---|---|
| Order_ID | Unique transaction/order identifier |
| Order_Date | Order date |
| Customer_ID | Synthetic customer identifier |
| Product | Product name |
| Category | Product category |
| Region | Sales region |
| Sales_Channel | Online, Retail, or Distributor |
| Quantity | Units in the order |
| Unit_Price | Price per unit in INR |
| Discount | Discount fraction from 0 to 1 |
| Sales_Amount | Net sales after discount, in INR |
